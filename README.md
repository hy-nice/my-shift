# My Shift（マイシフト）

スマートフォンで勤務日と時間を選び、LINE送信用のシフト連絡文を作れる無料のWebアプリです。Google Apps Script（GAS）、ログイン、データベースは不要です。

## GitHub Pagesで公開する方法

1. GitHubでリポジトリ（例：`my-shift`）を作成します。
2. このフォルダ**内のファイル**をリポジトリの最上位にアップロードします。`index.html`が最上位にあることを確認してください。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、ブランチは **main**、フォルダは **/(root)** にして保存します。
4. 公開されたHTTPSのURLをiPhoneのSafariで開き、共有メニューから **ホーム画面に追加** を選びます。

## 使い方

1. カレンダーで勤務日を複数選択します。
2. 出勤・退勤時間を入力します。「よく使う時間」から選ぶこともできます。
3. 「選択した日に時間を適用」を押します。
4. 日によって時間が異なる場合は、その日だけ選び直して時間を変更します。
5. 「LINEで共有」からLINEを選ぶか「文章をコピー」で貼り付けます。

勤務日と定型時間は、この端末・ブラウザに自動保存されます。

## 注意事項

- GitHub Pages上のアプリ本体は公開されます。勤務データはGitHubにはアップロードされません。
- データは端末のブラウザの `localStorage` に保存されるため、ブラウザデータの削除・端末の変更などで消失する場合があります。端末間の自動同期はありません。
- 最初のアクセスと更新時にはネット接続が必要です。キャッシュ導入後はオフラインでアプリ画面を利用できます。
- 「LINEで共有」は端末の共有メニューを表示します。LINEを選択して送信してください（自動送信はしません）。
- 日をまたぐ夜勤（例：22:00〜翌6:00）はこのバージョンでは対応していません。
- アプリを同僚に共有する場合は、GitHub PagesのURLを伝えてください。各自の勤務データはそれぞれの端末に保存されます。
